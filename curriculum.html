DM001 · Concept-first Curriculum

12 次课，48 个
数据挖掘核心概念。

2026 版课程不再把课堂时间主要用于算法手算和代码操作。课堂聚焦概念、假设、模型思想与评价；实现、实验、比较与迭代主要通过 Agent 驱动的项目实践完成。

12 次概念课48 个核心概念Concept firstAgent-based project
课程主线

认识数据与问题 → 让数据可学习 → 发现结构 → 建立预测模型 → 理解机器如何学习 → 判断模型是否可信 → 进入真实应用。

01 · DATA认识数据

第 1–4 课：现实怎样变成机器可以处理的数据。

02 · PATTERN发现模式

第 5–6 课：没有标签时，数据中有哪些结构。

03 · MODEL学习预测

第 7–10 课：不同模型如何理解世界，又如何学习。

04 · EVALUATE判断与应用

第 11–12 课：模型是否可信，以及如何进入真实系统。

LESSON 02

从数据表示到学习问题

先决定数据怎样组织，再把现实问题翻译成机器可以学习的任务。
05

数据表示
Data Representation

表格、事务、文本、序列、图、图像等不同表示方式。

06

问题形式化
Problem Formulation

把现实问题翻译成分类、回归、聚类、关联、推荐等可计算任务。

07

目标变量
Target / Label

在预测任务中，明确机器最终希望解释或预测的变量。

08

监督学习 vs 无监督学习
Supervised vs Unsupervised

有没有已知目标，是学习任务最基本的分叉之一。

LESSON 03

真实数据的问题

模型之前，先判断数据是否值得相信。
09

数据质量
Data Quality

准确、完整、一致、可信与及时，是建模的前提。

10

缺失数据
Missing Data

“没有数据”可能是随机缺失，也可能本身携带信息。

11

噪声与异常值
Noise / Outlier

异常既可能是错误，也可能是最重要的发现。

12

数据集成与实体识别
Data Integration / Entity Resolution

来自不同数据源的记录如何对应到同一真实实体。

LESSON 04

怎样比较数据

“相似”不是天然存在的，它必须被定义。
13

标准化
Scaling / Normalization

避免不同量纲和数值范围扭曲模型判断。

14

距离与相似性
Distance / Similarity

用数学方式定义两个对象到底有多像。

15

相关 ≠ 因果
Correlation ≠ Causation

一起变化不代表一个因素导致另一个因素。

16

高维与维度灾难
Curse of Dimensionality

维度增加后数据变稀疏，相似性和学习都会变困难。

LESSON 05

从数据中发现模式

从“模式是什么”开始理解共现结构。
17

模式
Pattern

数据挖掘寻找的不是单个数字，而是非随机结构。

18

频繁模式 / 频繁项集
Frequent Pattern / Itemset

发现哪些事物经常共同出现。

19

支持度
Support

衡量一个模式在整个数据集中到底有多常见。

20

置信度
Confidence

衡量已知 A 出现时，B 出现得有多频繁。

LESSON 06

无监督结构发现

没有标签时，既可以寻找共现，也可以寻找自然群体。
21

Apriori / 剪枝思想

利用已经知道的“不可能”，大幅减少搜索空间。

22

聚类
Clustering

在没有人工标签时，寻找数据中的自然分组。

23

K-means 与质心

把“属于一群”定义为围绕同一个中心。

24

什么才叫一个 Cluster？

中心、层次、密度对应不同的“群体”假设。

LESSON 07

分类的基本思想

从“空间怎么被切开”进入监督预测。
25

决策边界
Decision Boundary

分类模型可以理解为在特征空间中划分不同区域。

26

KNN / 邻域思想

根据附近最相似的样本来推断未知样本。

27

Lazy vs Eager Learning

比较“先建模型再预测”和“预测时再计算”的学习方式。

28

Naive Bayes

把分类理解为基于证据更新类别概率。

LESSON 08

从树到线性模型

不同模型不是不同公式，而是不同的世界假设。
29

Decision Tree

通过连续提问，把复杂决策分解成简单判断。

30

Entropy / Information Gain / Gini

决策树选择问题的本质：尽可能减少不确定性。

31

Linear Regression

用简单函数逼近连续变量之间的关系。

32

Logistic Regression

先估计类别概率，再通过阈值完成分类。

LESSON 09

更强的模型表达能力

从稳健边界走向多层非线性表示。
33

SVM：Margin 与 Support Vector

不只要求分开，还希望找到更稳健的最大间隔边界。

34

Neural Network：神经元、隐藏层与非线性

通过多层简单变换组合，表达复杂关系。

35

模型
Model / Hypothesis

规定机器允许在什么样的函数空间里寻找答案。

36

参数
Parameter

模型真正从训练数据中学习得到的数值。

LESSON 10

机器到底怎样学习

把不同算法统一到“定义错误，并让错误变小”。
37

超参数
Hyperparameter

不由模型直接学习，而是决定模型如何学习的设置。

38

损失函数
Loss Function

先定义什么叫“错”，机器才知道什么叫“更好”。

39

优化
Optimization

寻找一组参数，使模型的目标函数尽可能好。

40

梯度下降
Gradient Descent

沿着让损失下降最快的方向逐步更新参数。

LESSON 11

复杂模型的学习与组合

会训练还不够，模型必须面对真正没见过的数据。
41

Backpropagation

把最终误差逐层分配给神经网络中的各个参数。

42

Ensemble Learning

组合多个不完全相同的模型，获得更稳定或更强的预测。

43

Training / Validation / Test

训练、选择与最终评价必须使用不同角色的数据。

44

Generalization

机器学习真正追求的是对未见数据仍然有效。

LESSON 12

模型可信吗，以及怎样用于真实世界

最终目标不是跑出一个分数，而是做出可信的判断与决策。
45

Overfitting / Underfitting

模型过于简单和过于复杂都可能失去真正的预测能力。

46

Model Complexity & Regularization

通过控制复杂度，让模型在拟合与泛化之间取得平衡。

47

模型评价体系

Confusion Matrix → Precision / Recall → Threshold → ROC / AUC。

48

Recommendation System 与真实世界决策

把表示、相似性、预测、评价等概念组合成实际智能系统。

教学原则：课堂重点回答“它是什么、为什么需要、解决什么问题、什么时候会失效”；代码实现、参数尝试、模型比较和结果可视化主要交给 Agent 与项目实践完成。
