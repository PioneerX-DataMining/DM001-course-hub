你要完成什么？

PioneerX-DataMining

这是 DM001 使用的 GitHub Organization（课程组织）。

打开课程组织 →
收到 GitHub 邀请→确认登录账号→接受邀请→成为组织成员

不要把“老师已经发送邀请”和“你已经加入组织”混为一件事。邀请发出后，你仍需要自己接受，加入才算完成。

三步加入课程组织

1

找到 GitHub 邀请

检查你登记课程时填写的 GitHub 已验证邮箱。GitHub 会发送一封包含组织邀请链接的邮件。

确认邀请的组织名称是 PioneerX-DataMining。如果暂时没有看到邮件，先检查垃圾邮件 / Spam。
2

打开邀请链接，并确认当前 GitHub 账号

点击邮件中的邀请链接后，GitHub 会打开邀请页面。先看右上角当前登录的是不是你登记课程时使用的 GitHub 账号。

如果浏览器里登录了另一个 GitHub 账号，先切换到正确账号，再接受邀请。
3

接受邀请（Accept invitation / Join organization）

在 GitHub 邀请页面点击接受邀请。GitHub 的具体按钮文字可能随界面更新略有变化，只要完成“接受组织邀请 / 加入组织”即可。

完成后，你就是 PioneerX-DataMining 的成员。后续课程仓库与小队权限会在这个组织内管理。

如何确认已经成功？

✓ 接受邀请后，这一步就完成了

老师的课程后台会把你的状态从“待接受邀请”刷新为“已加入”。你也可以打开 PioneerX-DataMining，确认自己已经能够以组织成员身份访问课程相关资源。

完成 T01 后，再继续 T02 · WorkBuddy × GitHub MCP，把 Agent 接到你自己的 GitHub 权限上。

没有收到，或者无法接受？

没有收到邮件

检查垃圾邮件；确认课程登记邮箱确实已经添加到 GitHub 账号并完成验证。

邮箱邀请打不开

邮箱邀请只能由绑定了同一邮箱且该邮箱已验证的 GitHub 个人账号接受。

邀请已经过期

GitHub Organization 邀请 7 天未接受会自动过期。告诉老师重新发送即可。

如果你后来换了 GitHub Username 或邮箱，请先回到 课程账号登记页重新提交最新信息，不要直接用另一个账号接受。

GitHub 官方说明

GitHub Docs：Inviting users to join your organization

官方说明：组织邀请通过邮件提供邀请链接；使用邮箱邀请时，该邮箱必须与 GitHub 个人账号中的已验证邮箱匹配；未接受的邀请会在 7 天后自动过期。
