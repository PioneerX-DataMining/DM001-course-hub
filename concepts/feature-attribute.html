Feature Space 是什么？

如果选择 d 个 Features，就可以把每个 Object 表示成一个 d 维向量。因此，每个 Object 都对应这个 d 维 Feature Space 中的一个点。

Attribute ≠ Attribute value · 一个关键区分

Height 是特征，
但 175 cm 不是。

属性（Attribute）是描述维度；属性值（Attribute Value）才是某个对象在这个维度上的具体观测。

Meaning before math · 先理解含义，再做计算

都是数字，
就能一样处理吗？

数据长什么样，不等于它在语义上是什么。点击三组数字，看看为什么“数字列”也可能完全不同。

AGE

年龄

18 · 19 · 20 · 21

数值差异有实际意义；20 岁比 18 岁大 2 岁。

STUDENT ID

学号

001 · 002 · 003 · 004

看起来是数字，但主要作用是标识对象；平均学号通常没有意义。

GRADE LEVEL

等级编码

1 · 2 · 3 · 4

可能表示 A/B/C/D 或低/中/高；数字只是编码，不一定代表等距。

先记住： “存成数字” ≠ “可以随便做数学运算”。后面还会继续讲数据类型与测量尺度。
