特征向量与特征空间 · Feature vector & feature space

多个特征（Features）放在一起，
数据对象（Object）就变成空间中的一个点。

这是后面 KNN、聚类、距离、决策边界和“高维空间”共同依赖的几何直觉。

特征空间（Feature Space）是什么？

如果选择 d 个特征（Features），就可以把每个数据对象（Object）表示成一个 d 维向量。因此，每个数据对象（Object）都对应这个 d 维特征空间（Feature Space）中的一个点。

数据对象（Object） → 特征向量（Feature Vector） → 数据点（Data Point）

属性 ≠ 属性值 · Attribute ≠ Attribute value

身高（Height） 是特征（Feature），
但 175 cm 不是。

属性（Attribute）是描述维度；属性值（Attribute Value）才是某个对象在这个维度上的具体观测。

属性（Attribute）属性值（Attribute Value）

05 / 05
特征取决于问题 · Features depend on the question

同一个数据对象（Object），
可以有完全不同的特征（Features）。

特征（Feature）不是对象天然携带的一张固定清单；我们为了一个问题，选择一种描述方式。

  • 本节重点建立 Feature / Attribute 的基本语言，不展开属性类型与测量尺度；这些内容留到下一概念。
