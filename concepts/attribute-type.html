02 / 03
Meaningful operations · 不要死背四个名字

问四个问题，
变量类型会自己出现。

经典数据挖掘教材的核心思路：一个变量属于什么尺度，取决于哪些比较和运算真正有意义。

Nominal · 名义尺度
只允许判断“相同 / 不同”。类别没有天然顺序。
血型：A ≠ B ✓
但 A > B ✗
Distinctness → Order → Difference → Ratio　每向右一步，都比前一种尺度多一种有意义的操作。

编码成数字，

变量类型会影响统计、编码、距离、相似性和模型处理方式。先做一个最常见的陷阱题。
